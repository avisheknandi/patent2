# IDF-B LaTeX project

Build: `make` (or `pdflatex main.tex` twice). Needs a standard TeX Live (packages: geometry, booktabs, longtable, colortbl, tabularx, fancyhdr, float, hyperref, amsmath, amssymb, lmodern).
The file `main.tex` is generated by `docs/build_latex.py` from `results/results.json`; you can also edit it directly.
Figures are in `figures/`.
